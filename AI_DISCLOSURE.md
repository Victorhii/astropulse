# AI Disclosure

This document declares the use of AI-assisted tools during the development of **Astropulse**, submitted to the 2026 NASA Space Apps Challenge.

---

## AI Tools Used

### Claude (Anthropic)
**Role:** Lunar data fetching and backend logic

Claude was used to assist in developing the server-side data pipeline, including the architecture and logic for fetching and processing lunar data. This covers the SPICE kernel integration, LOLA DEM HTTP Range request handling, thermal model implementation, and the scoring and ranking logic used in the site comparison engine.

### Gemini (Google DeepMind)
**Role:** UI layout and simulation frontend

Gemini was used to assist in designing and structuring the frontend user interface, including page layouts, component styling, and the WebGL simulation logic for the first-person lunar surface view and the interactive timeline mode.

---

## Human Oversight

All AI-generated output was reviewed, tested, and refined by the team. Final decisions on architecture, data sources, scientific accuracy, and user experience were made by human team members. AI tools were used as development assistants, not autonomous authors.

---

## Data and Scientific Sources

AI tools did not generate or fabricate any scientific data. All lunar data is sourced from verified NASA and partner repositories as listed in the project's resource declaration.
